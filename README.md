# v2g
Voice recognition to Google

一、概覽
- 單一檔案：index.html
- 運行環境：iPhone Safari（使用網頁語音辨識 webkitSpeechRecognition）
- 用途：表演者講出一個日期，網頁計出對應嘅撲克牌，然後跳轉去 Google 圖片搜尋嗰張牌

二、使用流程
1. 開啟 index.html，進入表演畫面，咪高峰開始收音
2. 表演者講出「X月Y號，非常好」
3. 程式辨識月份同日子，計算 總和 = 月 + 日
4. 用總和喺對照表搵出對應嘅牌
5. 跳轉到 Google 圖片搜尋，搜尋字眼為牌嘅中文名（例如「黑桃2」）

三、計算規則
- 總和 = 月份 + 日子
- 範圍：最細 2（1月1日），最大 43（12月31日）
- 2 至 43 每個總和都有對應嘅牌，全年所有日子都有效

四、牌嘅代號
- 花色：S = 黑桃，H = 紅桃，D = 方塊，C = 梅花
- 點數：A, 2-10, J, Q, K
- 排列規律：花色按 S → D → C → H 循環，點數每格加 3（K 之後回到 A）

六、跳轉
- 網址格式：https://www.google.com/search?tbm=isch&q=<搜尋字眼>
- 用 location.replace() 跳轉（唔會留低返回記錄）
- 用 redirecting 旗標防止重複跳轉
- 跳轉前清除自動重開計時器（restartTimer）

七、語音辨識
- Safari 間中會自行停止辨識，程式會自動重新開咪
- 改設定：程式碼入面 const CARD_TABLE = { ... }; 一段

八、測試用例
- 「1月1號，非常好」   → 總和 2  → 黑桃2
- 「2月3號，非常好」   → 總和 5  → 紅桃J
- 「1月5號，非常好」   → 總和 6  → 黑桃A
- 「12月15號，非常好」 → 總和 27 → 方塊Q
- 「12月31號，非常好」 → 總和 43 → 方塊8
