# v2g
Voice recognition to Google
1. 完整規格清單
A. 平台同技術
#	規格
A1	主要用 iPhone（iOS 26）同 Safari。Android 用 Chrome
A2	用瀏覽器內置嘅語音辨識（方案 A）
A3	網頁放喺 GitHub Pages（一定要 HTTPS），由你自己處理
A4	如果瀏覽器唔支援語音辨識（例如 iPhone 上面嘅 Chrome），就顯示提示，叫你轉用 Safari
A5	保持屏幕開住（Wake Lock）。如果失敗，就提示你喺設定入面將自動鎖定改做「永不」
B. 設定畫面
#	規格
B1	範圍選單：暫時只有「日子」，之後會再加。每個範圍有自己嘅識別規則同對照表
B2	語言選單：廣東話（zh-HK）／普通話（zh-CN）
B3	「開始表演」按鈕：撳完先開始收音
B4	自動記住上次揀嘅範圍同語言
B5	冇暗掣
C. 表演畫面
#	規格
C1	撳「開始表演」之後轉去乾淨畫面：黑底、白色大字、置中
C2	未聽到日子之前，畫面乜都唔顯示
C3	聽到日子之後顯示「5月12日」格式，唔理觀眾講「號」定「日」
C4	左上角有細狀態點：綠色代表收緊音，黃色代表重新連接中，紅色代表斷咗或者冇咪高峰權限
C5	唔使震機，唔使出聲
D. 日子識別
#	規格
D1	一定要有「月」同埋「日／號／号」先當係日子。淨係聽到數字唔會用
D2	只要月同日，唔要年份。2月29日都收
D3	唔存在嘅日子（例如 2月30日、13月5日）當聽唔到，畫面保持顯示上一個有效日子
D4	接受阿拉伯數字、中文數字、廿、卅、繁體字同簡體字。之後可以再調整
D5	未講確認字眼之前，日子可以不停改，以最後聽到嗰個為準
E. 確認同跳轉
#	規格
E1	確認字眼係「非常好」，由表演者講。句子入面有呢三個字就算，例如「非常好呀」都得
E2	聽到臨時結果有「非常好」就即刻跳轉，唔等最終結果
E3	未有日子就講「非常好」：唔理，繼續聽
E4	日子同「非常好」喺同一句：用「非常好」前面嗰個日子，即刻跳轉
E5	計算方法：月＋日 = 總和（2 至 43），再查對照表搵張牌
E6	跳轉之前先停咗收音，然後喺同一個分頁用取代方式去 Google 搜尋
E7	淨係搜牌名，例如「紅桃A」
E8	撳返回唔會返到你嘅網頁

G. 出錯同重新連接
#	規格
G1	收音自己停咗就自動重新開始，狀態點會轉黃色
G2	冇咪高峰權限或者重新開始失敗，狀態點轉紅色
